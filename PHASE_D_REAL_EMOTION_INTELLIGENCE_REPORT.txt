=======================================================
ARCHITECTURE DECISIONS
=======================================================

Decision 1 -- Dual-Mode NLP (no hard API dependency)
  Transformers.js loaded via dynamic import with try/catch.
  If model fails to download, lexicon fallback activates automatically.

Decision 2 -- Singleton EmotionEngine
  All callers share one instance with shared LRU cache.
  Max 500 cache entries. Prevents redundant inference.

Decision 3 -- EmotionProfile as InformationSignal field
  Signals carry pre-computed emotionProfile from ingestion pipeline,
  bypassing re-inference at decision time when available.

Decision 4 -- DecisionFactors is a flat object NOT an array
  factors: { senderTrust, neighborAgreementRatio, socialProofPressure,
  fearLevel, uncertaintyLevel, confidenceLevel, riskTolerance,
  effectiveCredibility, emotionIntensity?, primaryEmotion? }
  Tests must assert on flat properties or check reasoningSteps[].

Decision 5 -- RumorEngine API contract
  Start:   engine.start(signal, [patientZeroIds])
  Advance: state = engine.step()  -> returns SimulationState
  Count believers: [...state.agentStates.values()].filter(s => s === 'BELIEVER').length
