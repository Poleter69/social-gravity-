5. DESKTOP PACKAGING & OFFLINE DEPLOYMENT GUIDE
-----------------------------------------------
Social Gravity is structured for zero-cloud desktop packaging using Tauri.

[A] Prerequisites
  1. Node.js 18+ and npm
  2. Rust toolchain: `rustup default stable`
  3. Visual Studio C++ Build Tools (Windows)

[B] Building the Windows Desktop Installer (.msi / .exe)
  1. Install Tauri CLI (if not present):
     `cargo install tauri-cli`
  2. Compile production bundle:
     `npm run build`
  3. Package native Windows desktop app:
     `cargo tauri build`
  4. The installer is generated at:
     `src-tauri/target/release/bundle/msi/SocialGravity_0.1.0_x64_en-US.msi`

[C] Offline Model Storage Strategy
  To run GoEmotions 100% offline on air-gapped workstations:
  1. Download model weights once:
     `Xenova/distilbert-base-uncased-go-emotions`
  2. Place ONNX files into `public/models/go-emotions/`
  3. Configure `@xenova/transformers`:
     `env.localModelPath = './models/';`
     `env.allowRemoteModels = false;`
  4. In environments without ONNX WebAssembly support, the calibrated
     27-dimensional lexicon fallback activates with 0ms startup overhead.
