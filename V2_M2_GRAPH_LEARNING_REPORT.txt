complement Social Gravity's deterministic epistemic rules. Rather than replacing
the verifiable rule-based engine with an opaque neural network, we designed a
hybrid architecture that projects network topology into continuous vector manifolds

2. MATHEMATICAL SPECIFICATION
-----------------------------
1. 2nd-Order Walk Probability:
   Let t be the previous node, v be the current node, and x be the candidate next node.
   pi_{vx} = alpha_{pq}(t, x) * w_{vx}
   where:
     alpha_{pq}(t, x) = 1/p  if d(t, x) = 0 (return to t)
     alpha_{pq}(t, x) = 1.0  if d(t, x) = 1 (mutual neighbor)
     alpha_{pq}(t, x) = 1/q  if d(t, x) = 2 (explore outwards)

2. Skip-Gram with Negative Sampling (SGNS):
   Objective: Maximize log sigma(u^T * v) + sum_{k=1}^K E_{n ~ P_n}[log sigma(-u^T * v_n)]
   Gradients updated via Online Stochastic Gradient Descent with learning rate eta = 0.05.

3. L2 Normalization:
   Final target representations are normalized such that ||e_i||_2 = 1.0, enabling
   instant O(d) cosine similarity computation via dot product.
