================================================================================
SOCIAL GRAVITY — INSTALLATION & DEPLOYMENT GUIDE (v1.0.0-alpha)
Step-by-Step Setup for Local Development, Web Workstations & Desktop Bundles
================================================================================

1. PREREQUISITES
----------------
- Operating System: Windows 10/11 (64-bit), macOS 12+ (Intel or Apple Silicon),
  or Linux (Ubuntu 20.04+, Fedora 38+, Debian 11+).
- Node.js: Version 20.x or 22.x LTS (tested on Node.js v24.14.1).
- Package Manager: npm (v9+) or pnpm / yarn.
- Rust (Desktop packaging only): Rust 1.75+ and Cargo.


2. QUICK START (LOCAL WEB WORKSTATION)
--------------------------------------
The fastest way to launch the analyst dashboard on any machine:

Step 1: Clone or open the repository
  $ cd "social gravity"

Step 2: Install dependencies
  $ npm install

Step 3: Run the developer workstation
  $ npm run dev

Step 4: Open your browser
  Navigate to http://localhost:5173 (or port designated in terminal).


3. VERIFYING THE BUILD & RUNNING TESTS
--------------------------------------
To ensure your environment reproduces our published verification benchmarks:

1. Run the master test suite:
   $ npm test
   # Expected output: 20 test suites passed (100%), exit code 0.

2. Run the empirical validation suite (Benchmarks, Case Studies & Security):
   $ npx tsx tests/validationRunner.ts
   # Expected output: All 4 case studies, prediction benchmarks, and pen tests pass.

3. Test production bundling:
   $ npm run build
   # Expected output: Clean compilation in dist/ with code-split vendor chunks.


4. CLI DATASET INGESTION COMMANDS
---------------------------------
Social Gravity includes command-line tools for processing raw SNAP and Reddit data:

- Inspect Facebook SNAP dataset:
  $ npm run inspect:facebook

- Import Facebook ego-network:
  $ npm run import:facebook

- Generate Facebook topological report:
  $ npm run report:facebook

- Ingest Reddit conversation trees:
  $ npm run reddit:collect
  $ npm run reddit:report


5. DESKTOP APPLICATION COMPILATION (TAURI)
------------------------------------------
To package Social Gravity as a standalone desktop executable (.msi / .exe on Windows,
.dmg on macOS, .AppImage on Linux):

Step 1: Install platform build tools:
  - Windows: Visual Studio C++ Build Tools & Microsoft WebView2 Runtime.
  - macOS: Xcode Command Line Tools (`xcode-select --install`).
  - Linux: Run `sudo apt-get install libwebkit2gtk-4.0-dev build-essential curl wget libssl-dev`.

Step 2: Build the desktop app:
  $ npm run build
  $ npx tauri build

The standalone installers will be written to:
  `src-tauri/target/release/bundle/`


6. TROUBLESHOOTING & FAQ
------------------------
Q: Can Social Gravity run completely offline?
A: Yes. All simulation mechanics, dynamic graph algorithms, and GoEmotions
   emotion NLP execute 100% locally in-memory. Zero network access is required
   once node dependencies and local models are installed.

Q: How do I export an intelligence brief?
A: In the UI dashboard, open the Export Panel located on the top navigation bar.
   Choose "Export Brief (PDF)", "Export Data (CSV)", or "Export State (JSON)".
