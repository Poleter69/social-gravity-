3. API & MODULE ARCHITECTURE REFERENCE
--------------------------------------
The Social Gravity TypeScript codebase is structured into modular domains:

1. `src/simulation/`:
   - `engine.ts`: Core simulation tick loop, transmission evaluations, state transitions.
   - `streamingEngine.ts`: Async non-blocking generator loop for 60 FPS responsiveness.
   - `prng.ts`: SplitMix32 pseudo-random number generator for deterministic replay.
   - `types.ts`: Telemetry, transmission, and state interfaces.

2. `src/society/`:
   - `generators/`: Watts-Strogatz, Barabasi-Albert, SBM, and Archetype generators.
   - `metrics/`: Degree, betweenness, clustering, and eigenvalue centrality calculators.
   - `dynamicGraph/`: Temporal edge decay and triadic closure reinforcement engine.

3. `src/datasets/`:
   - `realDatasetService.ts`: Central dataset catalog and ingestion facade.
   - `snapFacebookAdapter.ts`: SNAP ego-network edge list and circle feature parser.
   - `redditAdapter.ts`: Hierarchical comment tree parser and thread graph constructor.

4. `src/nlp/`:
   - `goEmotionsClassifier.ts`: On-device ONNX/WASM Transformer model inference.
   - `affectiveModulator.ts`: Emotion vector to transmission probability conversion.

5. `src/counterfactuals/`:
   - `counterfactualEngine.ts`: Simulation state cloner and parallel branch runner.
   - `strategies.ts`: Bridge inoculation, broadcast debunking, and rate limiting implementations.

6. `src/live/`:
   - `liveManager.ts`: Multi-connector coordinator.
   - `redditConnector.ts`, `blueskyConnector.ts`, `rssConnector.ts`, `localStreamConnector.ts`.
   - `dedup.ts`: Sliding-window deduplication store.

7. `src/exports/`:
   - `pdfExporter.ts`: HTML/CSS executive intelligence brief generator.
   - `csvExporter.ts`: Multi-section CSV data tables with formula-injection defense.
   - `jsonExporter.ts`: Map/Set-aware replay state serializer.

8. `src-tauri/`:
   - Native Rust wrapper for cross-platform desktop compilation and sandboxing.
