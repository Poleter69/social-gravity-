1. EXECUTIVE SUMMARY
-------------------
Milestone M5 establishes a continuous empirical validation framework to certify
that Social Gravity's forward forecasts hold true when tested against unseen real
data observations. 

Rather than evaluating predictions on data the model has already observed, the
Continuous Evaluator implements a strict temporal holdout protocol:
1. Historical / Real Cascade Ingestion: Ingests ground-truth network trajectories.
2. Temporal Holdout: The simulation is blinded to all events occurring after a
   cutoff split tick (e.g. SplitTick = 2, hiding T > 2).
3. Blind Forecast Generation: The rolling Forecast Engine generates forward
   projections strictly using information available at or before SplitTick.
4. Ground-Truth Parity Evaluation: Blind forecasts are compared against the
   unhidden future observations across MAE, RMSE, Recall, Precision, Brier calibration,
   and temporal forecast drift.
5. Persistent Benchmark Database: Historical results are logged to track
   algorithm performance improvements or regressions across engine iterations.


2. METHODOLOGY & EXPERIMENTAL SPLIT
-----------------------------------
- Test Network: Holdout Validation Society (N=70 nodes, modular community structure).
- Threat Narrative: Emergent Smart Contract Liquidity Exploit (Arousal = 0.90).
- Temporal Protocol:
  * Full Horizon Observed: 6 ticks.
  * Holdout Cutoff (Split Tick): 2 ticks.
  * Blind Forecast Horizon: 4 ticks forward.
- Evaluation Metrics:
  * Mean Absolute Error (MAE): |Predicted Adoption - Actual Adoption|
  * Root Mean Square Error (RMSE): sqrt((Predicted Adoption - Actual Adoption)^2)
  * Outbreak Detection Recall: True Positive Outbreaks / Actual Outbreaks
  * Brier Calibration Score: (Predicted Probability - Actual Outcome)^2
  * Forecast Drift: Deviation between early adoption velocity and actual late velocity.
